Computer Science P Tips

  1. Why does this matter?

    • AP Computer Science Principles is important because it helps you have a very strong intro into why coding as a whole matters

    • Coding is everywhere around you (including making this webpage viewable to you :D!)

    • We covered this so we can start with some motivation before we go deep into AP CSP

  2. What is the best approach to do well in this class?

    • This course can be taught in a variety of different languages so it really differs

    • I was taught this class in javascript but I will try to give the best, comprehensive tips I can!

  3. How can I practice Computer Science Principles

    • I think that the best strategy is to use code.org

    • Making labs, doing projects,doing practice problems on code.org was very helpful.

    • Code.org does a really good job at convering key topics so be sure to ask your teacher for access to this website!

  4. How about for the FRQs?

    • The FRQs are based on code YOU wrote so make sure you understand what is going on in your code :)

    • There really is not much more of a tip that I can give, because it really is like dependent on what you make ahead of time.

  5. What is a non-negotiable in this class?

    6. THIS IS SUCH AN IMPORTANT QUESTION SO LISTEN UP!

    • You need to have REALLY GOOD TIME MANAGEMENT

    • For this class, you will need to submit a portfolio so make sure you pay attention and submit this way before the due date (you will need this for your AP test)

    • You can't really cram coding so make sure to study and practice WELL in advance!

  6. Is this class anything like CSA?

    • Honestly no...

    • CSA is very deep into Java and I think that CSP is more accessible for beginners.

    • I also feel CSA focuses more on your technical skills rather than fundamentals that CSP teaches
